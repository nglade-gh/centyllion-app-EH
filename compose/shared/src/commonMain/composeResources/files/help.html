1. Introduction

NetBioDyn est un environnement de modélisation et de simulation multi-agents sur grille. Il permet de décrire un modèle (des grains, des comportements, des champs), puis de le simuler pas à pas sur une grille carrée.

Le modèle décrit qui peut changer, comment, et sous quelles conditions. La simulation fait évoluer l'état de la grille en appliquant les comportements à chaque pas.

Idée directrice

Chaque case de la grille peut contenir un agent (un grain) ou être vide. À chaque pas, chaque agent examine son voisinage (les 8 cases autour de lui) et peut déclencher un comportement qui modifie sa case et/ou les cases voisines.

2. Le modèle

Le modèle regroupe trois types d'éléments :

ÉlémentRôleExemple
GrainUn type d'agent, avec une couleur, une demi-vie, une probabilité de mouvement.« Bleu », « Rouge »
ComportementUne règle de transformation : un réactif central, des voisins réactifs, des produits, et des conditions.« Bleu → Rouge »
ChampUne grandeur continue diffusant sur la grille (comme un chimique).« Nutriment »

2.1 Les grains (agents)

Un grain définit un type d'agent. Ses propriétés principales :

  • Nom : le nom affiché dans l'interface.
  • Couleur : la couleur de l'agent sur la grille.
  • Demi-vie (halfLife) : si > 0, l'agent meurt aléatoirement avec une probabilité croissante en âge. 0 = immortal.
  • Probabilité de mouvement : si > 0, l'agent peut se déplacer vers une case vide voisine.
  • Production de champ : l'agent émet un champ (par ex. un nutriment).
  • Perméabilité : l'agent freine ou laisse passer un champ.

Identifiant (ID)

Chaque grain possède un numéro d'ID unique, affiché dans la liste des grains et sur les agents de la grille (quand la case est assez grande). C'est cet ID qu'on utilise dans les formules, par exemple count(0) compte les voisins de l'agent d'ID 0.

2.2 Les comportements

Un comportement décrit une transformation locale. Il se compose de :

  • un réactif principal (la case centrale) ;
  • un produit principal ;
  • des réactions sur les cases voisines (réactif → produit, avec directions possibles) ;
  • des conditions : formule, probability, etc.

Exemple : prédation

Case centrale : A → vide
Voisin (B)   : B → B

Un agent A en contact avec un agent B est mangé (il disparaît). Le comportement s'applique si la case centrale contient A et si au moins un voisin contient B.

Exemple : génération spontanée

Case centrale : vide → A
Voisin (B)   : B → B

Un agent A apparaît sur une case vide si au moins un voisin B est présent. Le réactif principal none (vide) permet ce type de comportement.

Exemple : catalyse

Case centrale : A → B
Voisin (C)   : C → C

Un agent A se transforme en B en présence d'un catalyseur C.

2.3 Les champs

Un champ est une grandeur continue définie sur toute la grille, comme la concentration d'un nutriment ou d'une molécule. À chaque pas, le champ :

  1. diffuse vers les cases voisines (selon les directions autorisées et la perméabilité des agents) ;
  2. est produit ou consommé par les agents présents ;
  3. subit une mort exponentielle (demi-vie) ;
  4. peut être transformé par une formule.

Les champs permettent de modéliser des signaux chimiques, des gradients, des ressources, etc. Les agents peuvent les percevoir via les formules.

3. La simulation

La simulation fait évoluer la grille pas à pas. À chaque pas :

  1. les agents meurent (selon leur demi-vie) ;
  2. les agents vieillissent ;
  3. chaque agent examine les comportements applicables ;
  4. les comportements retenus sont appliqués ;
  5. les champs sont mis à jour.

Le nombre de pas et la vitesse sont affichés dans la barre d'outils.

3.1 Modes de mise à jour

Deux modes sont disponibles (bouton dans la barre d'outils) :

ModeDescriptionUsage
Parallèle
défaut		 Tous les comportements sont calculés à partir de l'état du début du pas, puis appliqués simultanément. Automates cellulaires, comptages de voisins, modèles déterministes.
Séquentiel Les comportements sont appliqués immédiatement, dans un ordre aléatoire. Un comportement peut voir les changements des précédents. Modèles dépendant de l'ordre, chaînes de transformations.

Pourquoi le mode parallèle est le défaut

Dans le mode parallèle, le comptage des voisins ne dépend pas de l'ordre de mise à jour : tous les agents « voient » le même état initial. C'est le comportement attendu pour la plupart des modèles.

4. Les formules

Les formules sont des expressions mathématiques ou logiques évaluées dynamiquement. Elles sont utilisées dans deux endroits :

  • la formule d'un champ : transforme la valeur du champ à chaque pas ;
  • la formule d'un comportement : condition d'application du comportement.

4.1 Syntaxe

Les formules utilisent une syntaxe proche de l'mathématique. Priorités (de la plus forte à la plus faible) :

  1. parenthèses ( )
  2. puissance ^
  3. multiplication *, division /, modulo %
  4. addition +, soustraction -
  5. comparaisons >, >=, <, <=
  6. égalité ==, différence !=
  7. et logique &&
  8. ou logique ||
  9. ternaire condition ? siVrai : siFaux

Opérateurs unaires

  • -x : opposé
  • +x : identité
  • !x : négation logique

Littéraux

  • nombres : 1, 3.14, 0.5
  • booléens : true, false
  • constantes : pi, e

Variables de champ

VariableDescription

Variables de comportement

VariableDescription
stepÂge de l'agent (pour une condition sur l'âge, utiliser step).

Âge d'un agent

Dans une formule de comportement, l'âge de l'agent est disponible sous le nom step. Pour conditionner un comportement à l'âge, écrire par exemple step >= 10.

4.4 Exemples — formules de champ

La formule d'un champ est évaluée à chaque pas pour chaque case, à partir de la valeur actuelle.

Exemple 1 : décroissance

current * 0.9

Le champ perd 10 % de sa valeur à chaque pas.

Exemple 2 : oscillation

(1 + sin(step/10)) / 2

Le champ oscille entre 0 et 1 avec une période d'environ 63 pas.

Exemple 3 : gradient spatial

x / 100

Le champ croît linéairement avec la coordonnée x.

Exemple 4 : diffusion conditionnelle

current > 0.1 ? current * 0.8 : 0

Au-dessus de 0.1, le champ décroît ; en dessous, il s'annule.

4.5 Exemples — formules de comportement

La formule d'un comportement est évaluée pour chaque agent susceptible de l'appliquer.

Exemple 1 : condition sur l'âge

step >= 10

Le comportement ne s'applique que si l'agent a au moins 10 pas.

Exemple 2 : comptage de voisins

count(0) >= 3 && count(0) < 5

Le comportement s'applique s'il y a entre 3 et 4 voisins de type 0.

Exemple 3 : combinaison de conditions

step > 10 && (count(1) > 3 || count(2) == 5)

Le comportement s'applique si l'agent a plus de 10 pas et s'il y a plus de 3 voisins de type 1 ou exactement 5 de type 2.

Exemple 4 : condition sur un champ

field(0, x, y) > 0.05

Le comportement s'applique si le champ 0 est supérieur à 0.05 sur la case.

Exemple 5 : condition de position

x == 0 || x == 99

Le comportement s'applique uniquement sur les bords gauche et droit de la grille.

5. Exemples complets

Automate cellulaire : jeu de la vie simplifié

Grains : 0 = mort, 1 = vivant.

Comportement "Naissance" : vide → 1, formule : count(1) == 3
Comportement "Mort"     : 1 → vide, formule : count(1) < 2 || count(1) > 3
Comportement "Survie"   : 1 → 1,   formule : count(1) == 2 || count(1) == 3

Prédation avec seuil de population

Grains : 0 = proie, 1 = prédateur.

Comportement "Prédation" : 0 → vide, voisin (1) : 1 → 1, formule : count(1) >= 1
Comportement "Reproduction" : 0 → 0, voisin (1) : 1 → 1, formule : count(0) > 5

Chimiotaxie

Grains : 0 = bactérie ; Champ : 0 = nutriment.

Comportement "Avancer vers le nutriment" : 0 → 0, voisin (vide) : vide → 0, formule : field(0, x, y) > 0.1

Conseil

Commencez par un modèle simple (quelques grains, un ou deux comportements), vérifiez le comportement pas à pas, puis ajoutez progressivement les conditions et les champs.
